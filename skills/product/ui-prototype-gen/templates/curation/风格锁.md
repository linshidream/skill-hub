# 风格锁护栏

> 定制层（logo / 品牌色 / 业务图标 / 插画）在策展层第 ③ 层 tokens 纪律之上叠加品牌识别，但**不得破坏 preset 的"减法 + 纪律"**。风格锁 = 定制资产必须与选定 preset 的密度 / 圆角 / 阴影 / 饱和度纪律一致。

## 为什么需要风格锁

策展层第 ③ 层把高级感固化为可量化纪律（1 套字体 / 低饱和主导 / 主色稀用 / 统一圆角 / 去重阴影）。定制资产是品牌识别的增量，但若不受约束——异源图标混入、品牌色铺满、插画风格打架——会瞬间击穿 preset 的纪律，回到"廉价感"。

风格锁护栏确保：定制增强识别，不破坏秩序。

## 六条护栏

### 1. 品牌色
- 替换 `--ant-color-primary`（差异大时 re-build 改 seed，见 `prototype-skeleton/tokens-override.md` 主色派生暗礁）。
- **不破坏 preset 饱和度规则**：极简主色占比 ≤ 10%；商务主色用于功能强调（主操作/选中态/链接）；活泼主色可饱和但限一个主色相。
- 辅助色仅用于语义态（success/warning/error/info），不引入额外装饰色相。

### 2. logo
- 放 header 或 sider 顶栏，不铺满、不重复。
- 尺寸遵循 preset 间距纪律（8pt 栅格），不破坏信息密度。
- 极简 preset：logo 单色或与中性色同阶；活泼 preset：可品牌色 logo。

### 3. 业务图标
- **统一用 `prototype-skeleton/icons/` 的 Lucide 图标**（stroke 2px, currentColor, 24×24 viewBox）。
- 不混 emoji、不混异源图标集（不同线宽/填充风格）——异源图标是风格打架的首要来源。
- 图标着色用 `currentColor` 继承父元素语义色（主操作 primary，次要 secondary）。

### 4. 插画
- 极简 / 商务高密度 preset：**不用插画**（减法纪律；用空态组件 `Empty` + 文案代替）。
- 活泼移动 preset：可用插画，但限同色系（品牌主色 + 中性），不引入异色相插画。
- 无授权插画不用；不臆造占位插画（P1 红线）。

### 5. 字体
- `thresholds.font_family_max = 1`：1 套字体。
- 品牌指定字体优先，但保持 preset 字阶层级（scale 数组逐级映射 `--ant-font-size-heading-1..5`）。
- 不为品牌字体破坏字阶层级或行高纪律。

### 6. 阴影
- 遵循 preset 阴影纪律：极简 / 商务克制（`0 1px 2px`，用 border 替代分层）；活泼可柔和（`0 4px 12px`）。
- 定制资产（卡片/抽屉/弹层）不引入额外投影风格；用 `--ant-box-shadow` 变量，不写死异值。

## 校验

风格锁作为 `设计自检清单.md` 的扩展 gate：自检时若发现定制资产违反上述任一条，记 fail 项，回 N2 重改。定制层与策展层第 ④ 层自检共用同一 gate，不另立流程。
